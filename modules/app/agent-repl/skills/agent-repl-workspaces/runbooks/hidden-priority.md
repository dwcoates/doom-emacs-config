# Hiding, showing and priority

- `-hidden` / `-shown` and `-priority` set the rest.
  - `-shown` ends with the workspace drawn in the sidebar, or with an error.
    On an async merge's hidden merge workspace it also reveals it, exactly as
    selecting it does.
  - A reveal is one-way: `-hidden` on a revealed merge workspace files it in
    the ordinary hidden section, where `-shown` brings it back.
