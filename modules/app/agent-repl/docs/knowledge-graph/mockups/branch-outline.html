Chats rail: drawing a thread's branches

Every variant draws the same extreme thread in a 272px rail (the real rail's width). The thread has a 9-turn linear opening, a 6-way fan-out, a 4-way split, and a "rabbit hole" of branch points nested 10 deep. The blue dots mark the shown path (what the chat page is displaying). Striped rows are indented so far that less than 90px is left for their text, which is where a row stops being readable. Click rows in "Re-root" and "Drill-down" to move around.

Recommendation from the discussion: chain collapsing (2.1) plus re-rooting (2.2), which is the "Re-root" panel. Its indent can never pass 3 levels, so it cannot overflow at any depth. The baseline panel shows what one-indent-per-turn does today, which motivated all of this.
