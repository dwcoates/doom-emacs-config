## Deliverables (`src/feed/merge/`, tests `test/feed/merge/`)

1. `merge.ts` — `drawFeedMerge(u, rc)` = the collapsed HEAD line: the ⇄ glyph (map `glyph.icon` "merge" to the glyph; unknown icon names → the generic glyph with a warning log, never an error — it is a name from a shared vocabulary), the label line verbatim, the runtime clock ticking from `started_at_ms` while `update`, stopped at `ended_at_ms` for success/error; the state badge: `update` → "merging" live badge (blinking/breathing), `success` → "merged" + the commit sha, `error.failed` → the summary sentence with a red accent, `error.abandoned` → "abandoned". No counts anywhere (R5).

2. `merge-body.ts` — `mergeBubbleBody: BubbleBodyRenderer`: draws from `view.rows()`: the TAB STRIP from the `mergeTab` rows in served order (a tab per row; label text + round decoration "tests (2)" only for round > 1; the state glyph per state: live = filled breathing dot, parked = ⏸-like paused glyph, settled.succeeded = hollow check, settled.failed = red ✗ — glyphs, not emojis), the ACTIVE tab = the last live/parked tab, else the last tab (local selection; the user's click wins until the next push adds a NEW tab); the body of the selected tab: RESOLVED tabs draw the row's own content — `queue`: the FeedMergeQueue snapshot as a list (ahead front-first, the current entry marked "you are here", behind nearest-first; each entry's label verbatim, `merging` entries show the front's active tab label (+round), `waiting` entries plain; each entry a cross-workspace click calling `SelectWorkspace{workspace: entry.workspace.ref}` (R8) with the refusal at the row); `merge`: the narration lines verbatim; `tests`: one block per suite — name, state glyph (running/passed/failed), the output as paint-class spans in a capped, scrolled pre block; AGENTIC tabs (pre_prompt, conflicts, fixes, post_prompt): the sub-feed rows whose `parent.row` equals that tab row's id, drawn through `view.drawRow(row)` (the ordinary path, chrome included) in feed order — with a `[data-nest]` region per tab; PARKED (conflicts/fixes only): the composed standing line + a paused badge above the rows, and the composer slot (`view.composerSlot`) placed INSIDE the parked tab so typed prompts land there (the host composer is Emacs's; the slot exists only in dev mode/bubble composers). Settled failed tabs show the summary sentence under the strip. Re-render on `view.onChange` preserving the user's tab selection. Breadcrumbs header line only when non-empty (R6).

3. `queue.ts`, `tests-tab.ts`, `tab-strip.ts` — split the base functions per message: `drawFeedMergeTab`, `drawFeedMergeTabLabel`, `drawFeedMergeQueue`, `drawFeedMergeQueueEntry`, `drawFeedMergeTestSuite`, `drawFeedMergeTestSpan`, `drawFeedMergeMergeLine`, each validating and exported.

4. CSS: a delimited `/* ---- merge bubble (src/feed/merge) ---- */` section: the tab strip (subtle, thin delimiters via `.list-rows` where rows stack), the queue list, the suite blocks; reuse the existing bubble classes for the frame.
